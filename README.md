# FindMyGuru - Tutor Marketplace & Pricing Plans

Official landing and pricing portal for **FindMyGuru** — India's premier tutor marketplace built to help teachers and institutes get discovered, connect with students, and grow their tutoring business.

## 🚀 Features

- **Modern Hero Section**: High-converting visual hero showcasing active tutor community, key value props, and direct CTAs.
- **Dual Plan System**:
  - **Subscription Plans**:
    - **Starter Plan** (Free): Profile & course listing, direct student contact.
    - **Growth Plan** (₹3,499): Higher search visibility, 1,000 bonus coins (10 leads).
    - **Pro Plan** (₹5,999 - Most Popular): Top search placement, 2,000 bonus coins (20 leads), Featured Badge.
    - **Elite Plan** (₹9,999): Priority above all other plans, 4,000 bonus coins (40 leads), Featured Badge, Priority Support.
  - **Coins Plan**:
    - **Starter Plan** (₹500 - 1,000 / INR): 1x coins, lifetime validity, 5-10 leads.
    - **Growth Plan** (₹1,001 - 3,000 / INR): 1.2x coins, lifetime validity, 12-36 leads.
    - **Power Plan** (₹3,001 - 10,000 / INR): 1.5x coins, lifetime validity, 45-150 leads.
- **Interactive Pill Toggle**: Smooth switching between Subscription Plan and Coins Plan.
- **Why Tutors Choose FindMyGuru**: Trust metrics, verified badge indicators, and transparent lead unlocking guide.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices.

## 🛠 Tech Stack

- **HTML5** & semantic markup
- **Vanilla CSS3** with modern design tokens & variables
- **Vanilla JavaScript** for interactive tabs and toast notifications
- **Google Fonts** (Plus Jakarta Sans & Caveat)
